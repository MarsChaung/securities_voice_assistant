# ADR-0007：Shadow 複核工作台

- 狀態：內部 Web Pilot 啟用
- 日期：2026-07-22

## 決策

建立專用 `shadow_review_results` 資料表與本機管理介面，讓知識／法遵複核者比較「核准標準答案快照」與「Shadow 模型改寫」，並標記為可接受、內容不正確、超出核准內容、遺漏限制或警語、包含安全風險、語氣不佳或其他問題。

資料表只接收不含原始問題的 Shadow evidence 與生成結果。保存欄位包括知識 ID／版本、來源 ID、標準答案與禁止延伸快照、模型與 Prompt 版本、生成延遲、輸出守門結果、人工複核標記及本機開發身分。原始問句、ASR 逐字稿與音訊一律不進入複核資料表。

## 一致性與稽核

- 同一知識版本、來源、模型與 Prompt 雜湊以確定性 key 去重，程序重啟不會重複建立候選。
- 生成錯誤以「無法產生」保存，用於統計但不可人工接受。
- 人工複核只允許待複核項目轉為可接受或不採用，完成後不可覆寫。
- 複核說明拒絕個資、帳號、密碼與驗證碼。
- 一般技術 Log 仍只保存中繼資料，不記錄標準答案、模型改寫或複核說明全文。

## 第一版限制

- 僅使用本機 development 身分模擬器；正式 SSO／RBAC 留待移入公司環境後整合。
- 尚未實作正式保存期限、匯出、刪除核准與多層複核流程。
- 工作台統計只能支持後續是否進一步評估 `controlled_llm`，不能自行啟用模型答案，也不能授權模型增加知識。
