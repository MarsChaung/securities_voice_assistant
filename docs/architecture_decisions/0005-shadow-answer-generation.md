# ADR-0005：受控答案生成 Shadow Pilot

- 狀態：內部 Web Pilot 啟用 Shadow；Controlled 尚未啟用
- 日期：2026-07-20；2026-07-21 補充背景執行決策

## 決策

新增 `shadow_llm` 回答模式。在核准知識命中後，本機模型執行有限改寫與確定性輸出守門，但 API 永遠回傳人工核准的 `standard_answer`。稽核只記模型、提示版本與雜湊、延遲、是否套用及 `shadow_only`／回退 reason code，不保存問題、標準答案或生成答案。

受控改寫器不接收原始使用者問題，只接收標準答案、禁止延伸、知識 ID、版本與來源 ID。這避免從問題複製未核准產品詞，也縮小提示注入與資料暴露面。輸出使用 strict JSON Schema、溫度 0；模型故障、格式錯誤或守門失敗都直接回退標準答案。

## 背景執行

Shadow 改寫不再位於 HTTP 主要回應路徑。核准知識命中後，API 先回傳 `standard_answer`，再將不含原始問句的 evidence 送入單工、有限容量的程序內背景佇列。同一知識 ID、版本與來源在相同程序內去重；生成錯誤可由下一次命中重試，佇列已滿則略過，不影響正式回答。

主要 `turn_decision` 事件只記排程狀態，背景完成後另寫 `shadow_generation` 事件，包含模型、提示版本／雜湊、延遲、Output Guard 結果及 reason code，不包含標準答案、生成答案或客戶問題。程序關閉時等待已接受的工作完成；現階段不承諾跨程序重啟保存，持久化工作佇列留待 Shadow 評測資料庫階段。

## 離線評測

使用 `Qwen3.6-35B-A3B-oQ4` 生成，並以不同模型 `gemma-4-31b-it-6bit` 執行離線 groundedness 審查。評測涵蓋目前全部 15 筆知識：

- 生成成功：15/15。
- 確定性輸出守門：15/15。
- 獨立 judge grounded：15/15。
- 8 筆安全改寫、7 筆保留核准原文。
- Generator 平均約 1.49 秒，P95 約 2.05 秒。

第一版曾因模型把問題中的「台股」複製到標準答案未記載的位置而被守門拒絕。最終決策不是放寬守門，而是完全移除改寫器的原始問題輸入。

## Controlled 啟用條件

目前結果只證明 15 筆合成評測可通過，不代表改寫已優於核准原文。切換 `controlled_llm` 前仍須觀察 Shadow 的成功率、延遲與回退 reason code，加入去識別真實問句、ASR 誤字、長句與提示攻擊案例，並由知識／法遵人員抽樣審查改寫品質。任何 judge 或人工審查只能拒絕啟用，不能授權模型新增知識。
