# ADR-0004：結構化 LLM 意圖路由

- 狀態：內部 Web Pilot 啟用，正式上線前仍須公司模型、法遵與資安核准
- 日期：2026-07-20

## 背景

確定性關鍵字規則無法可靠涵蓋自然問句。「美股交易時間有哪些」與「如何開複委託帳戶」的混合檢索在取得正確 intent 時都能命中核准知識，但原政策分類會先給錯 intent 或 default deny，導致知識在檢索前被排除。持續增加片語特例無法解決泛化問題。

## 決策

在個資與確定性硬性政策之後、核准知識檢索之前加入本機 LLM Intent Router。Router 只分類，不回答問題，使用溫度 0 與 strict JSON Schema，輸出最多兩個候選意圖、信心值、風險旗標及是否需要釐清。

支援三種模式：

- `disabled`：只使用既有確定性分類。
- `shadow`：呼叫 Router 並記錄安全中繼資料，但不改變決策。
- `controlled`：高於校準門檻、無風險且不需釐清時，才使用第一候選意圖；未知或風險結果只能拒答或轉人工。

模型失敗、逾時、格式錯誤、低信心或要求釐清時回退確定性結果。個資偵測、`POL-REFUSE-*` 與既有 handoff 結果不呼叫 Router，因此 LLM 無法覆寫硬性安全決策。`allowed_intents`、平台、知識生命週期、最低分數及歧義門檻仍在檢索層生效。

一般稽核只記模式、模型 ID、提示版本與雜湊、候選意圖、信心、風險旗標、延遲、是否套用及回退原因，不記問題、提示全文或模型原始輸出。

## 模型評測

使用繁體中文證券合成資料評估自然改寫、模糊近似及安全風險：

- `Qwen3.5-9B-MLX-4bit`：結構化輸出與風險辨識未達門檻，未採用。
- `Ornith-1.0-9B-6bit`：校正後仍有一般知識與 App 教學誤分類，未採用。
- `Qwen3.6-35B-A3B-oQ4`：44/44；安全意圖 29/29、風險辨識 15/15，平均約 1.91 秒、P95 約 2.17 秒。

內部 Pilot 採 `Qwen3.6-35B-A3B-oQ4`、最低信心 `0.8`。評測結果只代表目前 15 筆知識與合成案例，不代表正式環境核准。

## 後續條件

正式上線前須加入真實但去識別化的問句分布、ASR 誤字、多意圖、提示注入及長句案例，觀察 shadow agreement、錯誤拒答率與延遲；模型或提示版本變更必須重新執行完整評測。身分驗證與 RBAC 仍依既定規劃留待公司環境整合。
