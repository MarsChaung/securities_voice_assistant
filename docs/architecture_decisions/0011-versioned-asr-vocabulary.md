# ADR 0011：版本化 ASR 詞彙與誤辨別名

## 決策

第一版將語音辨識詞彙放在知識版本內，每組資料包含：

- 正確的語音辨識詞彙（canonical term）。
- 零到多筆經人工確認的 ASR 別名／誤辨詞。
- 穩定識別碼，用於草稿期間的新增、修改與刪除。

詞彙只能由知識作者在草稿狀態編輯，並與標準答案及問句變體一起送審、發布及封存。Runtime 只會讀取通過來源狀態、生效時間、到期時間與複審到期時間檢查的已發布知識。

## 執行規則

1. ASR context 優先使用已發布知識的正確詞彙，不放入誤辨別名。
2. 語音檢索失敗時，先以人工確認的別名做精確回復，再使用既有拼音相似度。
3. 同一別名不得在 Runtime 期間對應到不同知識；發布時若有效期間重疊，系統會阻止衝突版本上線。
4. 詞彙與別名只影響語音管道，不自動改寫 Web 文字輸入。
5. 別名不得包含客戶個資、帳號、密碼、驗證碼或未經整理的原始語音內容。

## 範圍

本階段只提供管理者手動維護。從 Shadow 或語音觀測自動產生「待確認別名建議」留待後續實作；建議不得未經人工審核直接進入正式詞彙。
