# ADR-0008：FAQ 標準答案與問句變體共同治理

- 狀態：已實作核心資料模型與本機管理介面
- 日期：2026-07-23

## 決策

一組「標準答案＋多筆問句變體」視為一項 FAQ 知識項目。知識項目負責
`draft → review → approved → published` 生命週期；問句變體是知識項目的子資料，
不建立另一套審核狀態。

作者只能在草稿狀態編輯標題、標準答案及問句變體。問句變體使用穩定 ID，並標示為：

- `retrieval`：參與正式詞彙與向量檢索。
- `evaluation_only`：只供後續離線評測。
- `excluded`：保留分類結果，但不參與 Runtime。

目前問句保存在 `knowledge_question_variants` 關聯表；建立複審新版時，發布版本的
標準答案與完整問句變體會一起保存於不可變 JSON 快照。新版發布前，舊快照不會被修改。

## 檢索

詞彙檢索會對知識主體與每筆 `retrieval` 問句分別評分，採最佳問句分數，避免把大量
問句串接後稀釋重疊率。混合檢索則分別為知識主體及每筆正式問句建立向量表示，採最高
cosine similarity 與詞彙分數加權。`evaluation_only` 與 `excluded` 不進入 Runtime。

相同知識內正規化後重複的問句會被拒絕；同一正式問句若已屬於另一知識項目，也會被
拒絕，以免建立確定性的跨知識衝突。系統不自動刪除高度相似但不完全相同的問句。

## 範圍

本次只完成核心治理、人工編輯及 Runtime 整合。Excel 批次匯入預覽與內部 FAQ 來源
類型由 ADR-0009 接續；近似問句建議及大量資料的向量索引策略另行實作。
