# ADR-0003：受控答案生成與未來 LLM 意圖分類邊界

- 狀態：安全骨架已實作；受控生成預設關閉，待模型評測與內部核准
- 日期：2026-07-19

## 決策

Runtime 支援四種互斥回答模式：

- `exact`：預設模式，直接回傳人工核准的 `standard_answer`。
- `shadow_llm`：執行受控改寫與輸出守門，但永遠回傳人工核准的標準答案。
- `controlled_llm`：只把單筆匹配知識的標準答案、禁止延伸、知識 ID、版本及來源 ID 送入本機 OpenAI 相容模型做有限改寫；原始使用者問題不會送入改寫器。
- `fixed_message`：緊急安全模式；通過前置政策的問題也只回固定訊息，不執行知識回答。

`/voice-test` 後續加入的 `exact`／`natural` 客服回答選項是通話體驗層的策略，不取代
上述部署模式。`natural` 只在後端明確啟用時可選，會將本輪問題、最近有限對話及
單筆核准標準答案交給獨立自然回答器；既有硬性政策、知識生命週期、引用、輸出守門
與核准原文回退仍然共用。設計與限制見
[自然對話語音客服模式開發計劃](../plans/natural-conversation-voice-mode.md)。

`controlled_llm` 使用固定版本提示詞、溫度 0 與 JSON 物件輸出。輸出必須再通過確定性守門；若新增未核准數字或受保護產品詞、包含投資建議或交易承諾、提示詞洩漏、機敏資料、禁止延伸，或模型逾時、失敗及回傳格式錯誤，一律回退同一筆知識的人工核准標準答案。

一般稽核只記回答模式、模型 ID、提示版本與雜湊、生成延遲及回退原因，不記使用者問題、提示全文、標準答案或生成答案。

## 安全順序

以下確定性閘門在任何 LLM 呼叫之前執行：

1. 個資、帳號、密碼與驗證碼偵測。
2. 交易執行、個人帳務、投資建議、憑證處理與轉人工規則。
3. 已發布知識的生命週期、允許意圖、平台、最低分數與歧義門檻。
4. 受控改寫與輸出守門。

LLM 不得存取客戶、帳務或交易系統，也不得使用自身知識補充核准內容。

## 目前限制

這一版輸出守門採保守的確定性檢查，能攔截明確的新增數字、關鍵產品詞與高風險語句，但不能完整證明任意自然語言改寫都與來源語意等價。Phase 3.2 已依 [ADR-0005](0005-shadow-answer-generation.md) 加入獨立 groundedness judge 離線評測並啟用 `shadow_llm`；獨立 judge 不進入線上流程，也不能授權新增內容。`controlled_llm` 仍待更多真實分布評測後再決定。

## LLM 意圖分類

混合檢索適合找相近知識，但不應承擔所有自然問句的意圖判斷。此能力已依 [ADR-0004](0004-structured-llm-intent-router.md) 實作於硬性政策規則之後、知識檢索之前，輸出受 schema 約束，包含候選意圖、信心值、風險旗標與釐清狀態。

LLM 意圖分類只能協助辨識允許範圍內的問法，不得覆寫前置硬性拒答或轉人工決策。低信心、未知、同時包含多種意圖或風險旗標不一致時，必須回退、拒答、請使用者釐清或轉人工；模型或提示版本變更必須重新通過 ADR-0004 所述評測。
