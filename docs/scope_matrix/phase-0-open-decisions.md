# Phase 0 待核准事項

目前程式規則是保守的工程預設，僅供開發與測試，不代表正式政策。

| 決策 | 目前工程預設 | 所需核准角色 |
|---|---|---|
| 「如何下單」教學是否屬允許範圍 | 拒答 | 產品、業務、法遵 |
| 密碼、OTP、憑證與裝置綁定問題 | 拒答並導向官方管道 | 資安、客服、法遵 |
| 申訴、爭議與個資修改 | 轉人工 | 客服、法遵、個資 |
| 未命中或同時命中多個允許意圖 | Default deny | 產品、法遵 |
| 找不到已核准來源 | 拒答 | 產品、法遵 |
| 音訊、逐字稿與稽核資料保存 | 尚未實作持久化 | 法遵、個資、稽核 |
