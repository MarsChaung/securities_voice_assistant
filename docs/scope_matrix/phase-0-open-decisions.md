## 仍待跨單位核准

| 決策 | 目前工程預設 | 所需核准角色 |
|---|---|---|
| 密碼、OTP、憑證與裝置綁定問題 | 僅已核准的公開補發流程可回答；實際機敏值、代辦、一般忘記密碼、憑證與裝置綁定仍拒答 | 資安、客服、法遵 |
| 帳戶委任授權問題 | 僅已核准的公開說明與辦理流程可回答；代辦授權、帳密及實際帳戶狀態仍拒答 | 資安、客服、法遵 |
| 申訴、爭議與個資修改 | 轉人工 | 客服、法遵、個資 |
| 未命中或同時命中多個允許意圖 | Default deny | 產品、法遵 |
| 找不到已核准來源 | 拒答 | 產品、法遵 |
| 技術 telemetry 保存期限、儲存位置與存取角色 | 尚未決定 | 法遵、個資、稽核 |
| 是否另建法定客服稽核系統 | 不使用一般應用 log 代替 | 法遵、稽核、客服 |
