# 內部 Web Pilot 服務範圍 v0.1

- 狀態：專案範圍已確認；待業務、法遵、資安、個資與稽核單位核准
- 確認日期：2026-07-14
- 使用者：公司內部人員
- 通道：Web

## 系統邊界

- 不登入、不識別客戶，不接收或驗證客戶身分。
- 不連線交易、帳務、庫存、成交、交割、客戶主檔或憑證系統。
- 僅能使用公開或已核准且未過期的知識。
- 沒有充分核准來源時拒答，不使用模型自身知識補答。
- Web 是服務通道；知識內容可涵蓋國泰證券 App 與樹精靈 App 的公開操作教學。
- Phone、SIP、CTI 與正式客戶服務不在此階段範圍。

## 允許回答

- Web 公開畫面、功能及標準操作教學。
- 國泰證券 App 與樹精靈 App 的公開畫面、功能及核准操作教學。
- 「如何下單」的純操作教學，例如入口位置、畫面欄位與核准標準步驟。
- 一般開戶流程、公開產品規則、服務時間、公開費率與證券名詞。
- 官方聯絡方式及核准的常見錯誤排除步驟。
- 已人工核准的手機號碼變更與密碼補發「公開辦理方式」；不得接收實際密碼、
  驗證碼或要求系統代為補發。
- 已人工核准的帳戶委任授權說明與公開辦理流程；不得代客設定授權、接收帳密或查詢
  實際帳戶狀態。

## 下單教學與交易請求的界線

下單教學只能說明一般操作，不得代替使用者執行、接收或確認任何委託。系統不得要求或處理商品、方向、價格、數量、帳號、密碼、OTP 或憑證。

以下情況必須拒答：

- 要求系統下單、買進、賣出、改單、刪單或取消委託。
- 教學問題中混入代客交易要求。
- 無法確認是一般教學或真實交易指令。
- 要求針對特定商品提供買賣建議、價格預測或時點判斷。

## 必須轉人工

- 申訴、消費爭議或權益受損。
- 修改個人資料或查詢個人申請狀態。
- 核准標準排除步驟仍無法解決的問題。
