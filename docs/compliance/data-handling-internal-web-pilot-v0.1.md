# 內部 Web Pilot 資料處理規格 v0.1

- 狀態：專案原則已確認；待法遵、資安、個資與稽核單位核准
- 確認日期：2026-07-15
- 適用範圍：內部 Web Pilot

## 已確認原則

- 不持久化原始音訊。
- 不持久化完整 ASR 逐字稿或使用者輸入文字。
- 一般應用 log 不記錄原始輸入、遮罩後全文、回答全文或 request body。
- 技術 telemetry 僅保存必要中繼資料。
- 評測資料只能使用合成或完成去識別的內容，並與 runtime telemetry 分開管理。

## Runtime 資料流程

| 資料 | 用途 | 處理方式 | 一般 log |
|---|---|---|---|
| Web 麥克風音訊 | 即時 ASR | 僅在記憶體串流處理，使用後釋放 | 禁止 |
| ASR 逐字稿／文字輸入 | 敏感資料偵測與政策判斷 | 僅保留單一 turn 的記憶體生命週期 | 禁止 |
| ASR 領域詞彙 context | 優先由當下有效知識的受治理正確詞彙產生，未設定時使用標題與產品名稱；不包含誤辨別名 | WebSocket session 記憶體，連線關閉即釋放 | 禁止 |
| ASR 別名／誤辨詞 | 人工整理且不含個資的誤辨文字；隨知識版本審核與封存 | 依知識治理版本週期 | 禁止原始語音與客戶資料 |
| 偵測到的敏感值 | 中斷一般回答 | 不送往知識庫或 LLM，使用後釋放 | 禁止 |
| 敏感資料類型 | 稽核政策命中 | 只記錄類型，例如 `otp`，不記錄值 | 允許 |
| 回答文字 | Web 顯示或未來 TTS | 僅在記憶體處理 | 禁止全文，只記字數 |
| TTS 參考音檔與逐字稿 | 地端 voice clone | 僅由私有設定傳給宿主機 MLX Audio，不納入版控 | 禁止 |
| 瀏覽器語音播放與插話時序 | 診斷串流中斷、片段邊界與 Barge-in 校準 | 依核准答案字數決定 0.96–1.44 秒目標緩衝，實際初始等待上限 1.6 秒；僅記錄相對抵達時間、片段長度、排定播放時間、緩衝、underrun、插話模式、duck／confirm 延遲及誤觸次數 | 允許；禁止音訊、逐字稿與問答內容 |
| 慢回答等待提示音 | 降低安全查核與知識回答期間的感知等待 | 依既有對話分類選擇固定提示音；多輪語意尚在解析時從兩個中性音檔選擇且不連續重複。僅記錄 variant、觸發延遲及正式答案就緒延遲，不記錄提示音、問句或答案內容 | 允許 |
| Shadow 標準答案快照與模型改寫 | 內部人工複核 | 保存於專用複核資料表；不含原始問句或音訊 | 禁止 |
| Shadow 複核標記與說明 | 品質統計與開放判斷 | 保存本機複核身分、固定分類與去敏說明 | 禁止全文，只記一般技術中繼資料 |
| 核准 FAQ Excel | 建立知識草稿預覽 | 原始檔僅在單次請求記憶體解析，不保存；另存解析列、SHA-256 與來源追溯欄位 | 禁止檔案與內容全文 |
| 政策與來源中繼資料 | 技術稽核與除錯 | 採固定欄位白名單 | 允許 |

## 一般技術 telemetry 白名單

- Event schema version。
- Turn ID。
- `answer | refuse | handoff` 決策。
- Intent 與 policy rule ID。
- Knowledge ID、版本與來源 ID；目前尚未接入時為空陣列。
- 敏感資料類型，不包含原值。
- 輸入與輸出字數，不包含原文。
- 總延遲與錯誤類型，不包含 exception message 或 request body。
- 語音合成模型 ID、句子／音訊片段數、首段與完整 TTS 延遲及固定錯誤類型，不包含音訊或回答全文。
- 瀏覽器語音片段的相對抵達／排定播放時間、片段長度、初始緩衝、crossfade、underrun、插話模式、duck／confirm 延遲與誤觸次數，不包含音訊、逐字稿、問答內容、音量樣本或裝置識別資訊。

任何新增欄位都必須先更新資料分類與測試，不得透過任意 `extra` 欄位繞過白名單。

## 評測資料

- Repository 內的黃金案例必須明確標示 `synthetic: true`。
- 不得從 production log 複製原始對話建立案例。
- 去識別資料若未能證明已完成審查，不得進入 repository。
- 真實資料的合法依據、存取權限、保存期限與刪除程序未核准前，不納入 Pilot。
- Shadow 複核資料只能由不含原始問句的核准知識 evidence 產生，不得貼入客戶對話補充判斷。

## 仍待核准

- 技術 telemetry 的保存期限、儲存位置與存取角色。
- 是否需要獨立的法定客服稽核系統；若需要，必須與一般應用 log 分離設計。
- 事件調查時的授權、匯出、刪除與停止處理程序。
