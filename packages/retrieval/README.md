# Retrieval package

目前提供知識 catalog schema 驗證、來源追溯、PostgreSQL `published`／有效期過濾，以及具意圖、平台、最低分數與歧義門檻的確定性詞彙檢索。查詢正規化會合併已核准的操作與比較型同義問法，例如「不一樣」、「不同」、「差異」與「差在哪」會視為「差別」。

Runtime 只回傳人工核准的 `standard_answer`，並附知識版本、官方來源 URL 與段落定位。`hybrid` 模式會以 40% 詞彙分數與 60% cosine 語意分數進行排序，使用獨立的最低分數 `0.40` 與歧義差距 `0.02`；文件向量依知識 ID、版本、前綴及內容雜湊保存在程序內快取。Embedding 端點失效時 Runtime 以原本的 `0.55`／`0.08` 門檻退回詞彙檢索，但離線比較會直接失敗以避免掩蓋故障。

目前15筆知識不需要額外向量資料庫；未來文件量或多程序部署增加後，再評估 PostgreSQL `pgvector` 與受治理的索引重建流程。LLM 仍不會改寫或自由生成答案。
